# Task Manager

Um simples gerenciador de tarefas desenvolvido em Python como projeto prático
para demonstrar conhecimentos básicos de Git e GitHub.

## Funcionalidades

- Adicionar tarefas
- Listar tarefas
- Marcar tarefas como concluídas
- Remover tarefas

## Tecnologias

- Python 3
- Git
- GitHub
